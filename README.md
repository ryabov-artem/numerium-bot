# 🔢 Нумериум

Telegram-бот для AI-разборов по классической нумерологии.

Бот работает как самостоятельный продукт в сети эзотерических Telegram-ботов.

Telegram:

```text
@numerium_ai_bot
```

## Инфраструктура

* отдельный GitHub-репозиторий;
* отдельный Telegram Bot;
* отдельная SQLite база данных;
* отдельный YooKassa ShopID;
* отдельный webhook;
* отдельный systemd-сервис;
* отдельный скрипт резервного копирования;
* локальные и облачные бэкапы.

---

## Пути на сервере

Проект:

```text
/opt/bots/numerium_bot
```

База данных:

```text
/opt/bots/numerium_bot/data/database.db
```

Локальные бэкапы:

```text
/opt/backups/numerium
```

Google Drive:

```text
TG_Bots/Numerium
```
